# Puzzle explanations
When I work on and eventually solve what I think is an interesting (math) puzzle, I usually also have the desire to write up a solution in LaTeX. I don't know why I do this to myself, but I just do. LaTeX makes some pretty documents darn it.

This repository contains the LaTeX source to solutions for several problems, but it's pretty meager right now. Writing is difficult, and it goes slowly. What Ernest Hemmingway said about writing resonates with me (if he really said it): 
> There is nothing to writing. All you do is sit down at a typewriter and bleed.
